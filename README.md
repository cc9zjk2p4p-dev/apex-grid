# Apex Grid

A tiny, original browser-based motorsport strategy prototype.

## Run it
Open `index.html` in a modern browser. No build tools, server, or dependencies required (Google Fonts are optional; the game itself runs offline).

## How to play
1. Press **Start Race** / **Next Lap** to advance through 12 laps.
2. Use **Attack Mode** to spend energy for extra pace.
3. Use **Manage Tyres** to conserve rubber and recharge energy.
4. Take one pit stop for fresh tyres, at the cost of track position.
5. Finish the race and try to win.

## Project structure
- `index.html` — game layout
- `style.css` — responsive visual design
- `game.js` — race state, strategy, leaderboard, and track drawing

## Prototype scope
This is a lightweight strategy-game starting point, not a simulation of real F1 rules, teams, drivers, or circuits. All names and visuals are original placeholders. The project is not affiliated with Formula 1, Formula One Management, or Hutch.
